## EP-0173

- 확정 연결 에피소드: -

**시작 배경** 계약·신청·결제 마감 추적 앱(⟦앱A⟧) 아이디어를 ChatGPT와 검토하던 대화가 이전 묶음에서 이어져 왔다. 사용자는 이를 Claude Code로 바이브코딩하기로 마음먹은 상태였다.

**사용자의 목표** 앱 개발 경험이 없는 상태에서 안드로이드 MVP를 Claude Code로 만들 수 있도록 기술 판단과 세션별 실행 프롬프트를 확정하는 것.

**진행** 준비물과 주의점, 로컬 DB 필요 여부, 웹과 앱의 구조 차이, 테스트·배포 방법, 비용과 광고를 차례로 물었다(E01675, E01676). 이후 MVP 개발 플랜을 받은 뒤 기획·디자인까지 포함한 Claude Code 세션별 프롬프트를 요청하고, '분석·검증·시뮬레이션 후 다시 작성'을 여러 차례 반복시켰다(E01677). 앱 이름을 ⟦앱A⟧로 정하고 ko/en 다국어를 추가했으며 루트 디렉토리를 고정했다(E01678). 7세션 분할이 효율적인지 재검증을 시켜 4세션 구조로 바꿨고, 이미지로 보여준 폴더 구성을 확인받은 뒤 프롬프트 파일은 따로 만들지 않고 직접 복붙하기로 했다(E01679, E01683).

**AI의 제안·행동** ChatGPT는 서버 없는 로컬 저장 MVP, 내부 테스트 트랙 배포, 초기 비용은 Play 개발자 등록비 정도라고 정리했다. 매 요청마다 '최종본'을 다시 쓰면서 Flutter 로컬 스택으로 용어를 통일했고, 마지막에는 7세션은 과하고 4세션이 효율적이라고 판단을 바꿨다.

**사용자 반응** 사용자는 Room(SQLite)이 무슨 뜻인지 모르겠다고 했고, ChatGPT가 앱 안에 넣는 광고로 답하자 출시 홍보 광고를 물은 것이라고 바로잡았다. '개선사항이 있으면 안되 완벽하게' 하라며 검증을 거듭 요구했다.

**확인 가능한 결과** 앱 이름 ⟦앱A⟧, Flutter 기반 로컬 MVP, ko/en 지원, CLAUDE.md·SESSION_SUMMARY.md·docs 구조, 4세션 실행 순서가 정해졌다. 실제 개발 결과는 W14-02에서 이어진다.

## EP-0176

**앱을 다 만들었는데 폰에서 어떻게 보나: Claude Code의 세션 오해부터 첫 APK 점검까지**

- 시기: 2026-04-24 ~ 2026-04-24
- 프로젝트: 앱 (`APP`)
- 유형: 첫 완성·출시, AI의 잘못된 지시·판단, 예상치 못한 문제, ChatGPT와 Claude의 다른 판단
- 상태: 완료
- 출판 표시: 출판 후보
- 플랫폼: ChatGPT
- 확정 연결 에피소드: -

**시작 배경** W14-01에서 정한 세션 프롬프트를 Claude Code에 넣기 시작한 날이다. 사용자는 앱 개발과 실행 환경을 처음 다뤘다.

**사용자의 목표** Claude Code로 만든 앱을 실제 안드로이드 폰에서 실행·확인하고, 배포 전 무엇을 준비해야 하는지 알아내는 것.

**진행** 개발 성공을 가정한 다음 단계를 묻다가, 완성된 앱을 자기 폰에서 어떻게 보는지 모르겠다고 다시 물었다(E01685). 공통 시작 프롬프트만 넣었는데 Claude Code가 Flutter 미설치를 이유로 구현 옵션을 묻자 ChatGPT에 붙여넣었고, 세션 목적을 잘못 해석한 것이니 /clear 후 '구현 금지' 문장을 넣어 다시 시작하라는 안내를 받았다(E01686). 미리 가입할 것, Flutter·Android Studio 설치법, DB 추가 업데이트 시 기존 기록 보존 여부, ChatGPT가 테스트해 줄 수 있는 범위, '5개 등록하면 광고 시청' 구조를 물었다(E01687, E01688, E01689). 이후 디버그 APK를 올려 정적 점검을 받았다(E01690).

**AI의 제안·행동** ChatGPT는 Claude Code의 응답을 세션 목적 오해로 진단하고 재입력 문구를 써 주었다. APK는 정상적인 Flutter 디버그 빌드로 보인다고 정적 점검 결과를 보고했고, 실기기 동작은 직접 못 본다고 선을 그었다. 강제형 보상 광고는 MVP 검증을 망친다며 비추천했다.

**사용자 반응** 사용자는 '어디서 뭘 어떻게 해야하는지 방법이 중요해 그걸 모르겠어'라며 구체적 방법을 요구했고, ChatGPT가 무엇을 테스트해 줄 수 있는지 되물었다.

**확인 가능한 결과** 디버그 APK가 만들어져 ChatGPT가 정적 점검을 했다(AI의 점검 보고). 이어 E01691에서 사용자가 알림 동작까지 직접 확인했다고 밝혔다.
