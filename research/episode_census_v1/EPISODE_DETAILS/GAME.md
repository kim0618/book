## EP-0274

- 시기: 2026-08-05 ~ 2026-08-05
- 프로젝트: 게임 (`GAME`)

**시작 배경** 사용자가 만든 공 개수 성장형 벽돌깨기 게임의 전체 구조와 화면 캡처를 ChatGPT에 보여줬다.

**사용자의 목표** 게임의 디자인 보완점과 더 나은 이름을 찾는 것.

**진행** 사용자가 게임 구조 설명과 화면을 올리고 디자인 관점 보완점을 물었다(E02167). ChatGPT는 공 개수가 자원이자 난이도 기준인 구조를 강점으로 평가했다. 사용자가 이름 후보 '⟦자사 이름⟧'을 내자 ChatGPT는 ⟦자사 이름⟧를 가장 추천하고 ⟦자사 이름⟧은 연출 키워드로 쓰자고 했다(E02168). 사용자는 ⟦자사 이름⟧ 로고를 요청했다(E02169).

**AI의 제안·행동** ChatGPT가 게임 구조 평가, 이름 점수 비교, 이름은 ⟦자사 이름⟧·연출 키워드는 ⟦자사 이름⟧이라는 절충안을 제시했다.

**사용자 반응** 사용자는 이름 후보를 직접 제안했다가 가장 추천하는 것을 묻고 ⟦자사 이름⟧로 로고를 요청했다.

**확인 가능한 결과** 게임명 '⟦자사 이름⟧'로 로고 제작을 요청함. 로고 결과물은 확인 불가.

**시작 배경** 이름을 정한 뒤 사용자는 화면 디자인·레이아웃·색상을 전체적으로 손보려 했다.

**사용자의 목표** 현재 게임 화면 레이아웃을 유지한 채 일관되고 예쁜 디자인 시안을 얻는 것.

**진행** 사용자가 화면 캡처를 올려 재디자인을 반복 요청했고(E02170~E02192), 다른 AI의 배경 그림 요청 안내로 보이는 글도 붙여넣었다(E02171). 일시정지 화면 작업 중 이미지 생성 오류가 났고 사용자는 기존 시안과 어울리게 하라고 거듭 요구했다(E02195). 블록·아이템 디자인을 거쳐(E02247~E02257) 전체 일관성 진단을 받은 뒤 최종안을 요청했지만, ChatGPT가 UI를 새로 만들자 사용자가 '레이아웃을 바꾸지 말라'며 짜증을 냈다(E02263, E02265). 이후 로그인 판, 회원가입, 상단 점수 등 화면 하나씩 재디자인으로 방식을 바꿔 로그인·회원가입은 완료했다고 밝혔다(E02299~E02338).

**AI의 제안·행동** ChatGPT가 시안 이미지를 반복 생성하고, 전체 디자인을 '개별 화면 퀄리티는 올라왔지만 시스템 일관성은 부족'으로 진단했으며 회원가입에도 판을 깔자고 제안했다.

**사용자 반응** 사용자는 '이게 진짜 최선인지', '아니 계속 왜 새롭게 만들어', '하 짜증나' 등으로 불만을 표하고 하나씩 진행하는 방식으로 바꿨다.

**확인 가능한 결과** 사용자가 로그인·회원가입 화면 디자인 완료를 언급함(E02315). 나머지 화면 결과는 확인 불가.
