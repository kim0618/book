# 원본 아카이브 — 로컬 전용

이 디렉터리의 실제 원본은 회사 업무·사생활·계정·인증정보를 포함할 수 있어 Git에서 제외합니다. 이 안내 파일만 Git에 포함됩니다. 원본은 수정하거나 덮어쓰지 않습니다.

- `original_exports/`: 이전 작업이 복사한 ChatGPT·Claude 웹 원본 내보내기 자료.
- `local_logs_snapshot_20261022/`: 코딩 도구의 프로젝트·자동화 세션 원본 사본. 회사 업무는 사본 생성 대상에서 제외되어 원래 경로에 남아 있습니다.
- `per_conversation_fulltext/`: 모든 웹 대화의 텍스트 전개본. 메시지 번호·ID·역할·시각을 표시하며, JSON의 구조화된 이미지·첨부 자체를 대신하지 않습니다.
- `per_local_session_fulltext/`: 로컬 세션의 정규화 텍스트. 도구 호출·도구 결과는 원본 JSONL을 함께 확인해야 합니다.
- `recovery_state/`: 중단된 작업에서 복구한 스크립트·분류·정규화 메시지·검증용 입력. 원래 임시 파일이 사라져도 이어서 검증할 수 있도록 복사했습니다.
- `archive_integrity.json`: 사본의 SHA-256 및 원본 대조 내역. 비공개 파일 경로를 포함합니다.

사본 생성 전에 유실된 로컬 세션과 손상된 내보내기 첨부는 `MASTER_AUDIT.md`의 예외 목록을 확인하십시오. 텍스트 전개본의 존재를 원본 파일의 완전한 복구로 간주하지 않습니다.
