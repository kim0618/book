# **3. s3fs를 사용하여 서버에 버킷을 마운트하기**  
오브젝트 스토리지를 **서버의 로컬 디스크처럼 사용**하려면 `s3fs`를 이용하여 마운트할 수 있습니다.

## **① s3fs 설치 (리눅스 기준)**
```bash
sudo apt update && sudo apt install s3fs -y  # Ubuntu
sudo yum install epel-release -y && sudo yum install s3fs-fuse -y  # CentOS
```

## **② 인증 정보 설정**
```bash
echo "ACCESS_KEY_ID:SECRET_ACCESS_KEY" > ~/.passwd⟦비밀정보 가림: 비밀번호⟧
chmod 600 ~/.passwd⟦비밀정보 가림: 비밀번호⟧
```

## **③ 마운트할 디렉토리 생성**
```bash
mkdir ⟦로컬 경로⟧
```

## **④ 버킷 마운트 실행**
```bash
s3fs your-bucket-name ⟦로컬 경로⟧ -o passwd⟦비밀정보 가림: 비밀번호⟧=~/.passwd⟦비밀정보 가림: 비밀번호⟧ -o url=⟦URL⟧ -o use_path_request_style
```

✅ 이제 `⟦로컬 경로⟧` 경로에서 로컬 디스크처럼 오브젝트 스토리지를 사용할 수 있습니다.

### **⑤ 부팅 시 자동 마운트 설정 (옵션)**
```bash
echo "your-bucket-name ⟦로컬 경로⟧ fuse.s3fs _netdev,allow_other,use_path_request_style,url=⟦URL⟧ 0 0" | sudo tee -a /etc/fstab
```

# **4. Python SDK를 이용한 연동**
Python에서 `boto3`를 사용하여 오브젝트 스토리지를 연동할 수도 있습니다.

## **① boto3 설치**
```bash
pip install boto3
```

## **② Python 코드로 파일 업로드**
```python
import boto3

# 네이버 클라우드 오브젝트 스토리지 설정
session = boto3.session.Session()
client = session.client(
    's3',
    endpoint_url='⟦URL⟧',
    aws_access_key_id='네이버클라우드_액세스키',
    aws_secret_access_key='네이버클라우드_시크릿키'
)

# 파일 업로드
bucket_name = 'your-bucket-name'
file_name = 'test.txt'
client.upload_file(file_name, bucket_name, file_name)

print(f"{file_name} 업로드 완료!")
```

✅ 이 방식을 사용하면 Python 코드에서 오브젝트 스토리지를 쉽게 연동할 수 있습니다.
