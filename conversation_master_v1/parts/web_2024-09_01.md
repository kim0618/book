````text
CSS의 `position: fixed` 또는 `position: sticky` 속성을 사용하면 특정 요소가 스크롤에 따라 고정된 위치에 유지되거나 스크롤을 따라 움직이게 할 수 있습니다. 두 속성의 차이는 다음과 같습니다:

- `sticky`: 스크롤할 때 특정 위치에서 고정되다가 다시 스크롤되면 원래 위치로 돌아옵니다.

```html

            background-color: white; /* 스크롤 시 텍스트가 잘 보이도록 배경색 추가 */
            padding: 5px;
        }
````
