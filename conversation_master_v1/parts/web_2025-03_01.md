### **설명**
1. **`LIKE '%\%5E%'` 사용**  
   - `%5E` 앞에 **백슬래시(`\`)를 추가**해야 합니다.

2. **`REPLACE(category_nm, '%5E', '^')` 적용**

   - 예: `"multi%5E111"` → `"multi^111"`

### ✅ **이전 UPDATE 실행을 되돌리는 방법 (ROLLBACK)**  

#### 1️⃣ 트랜잭션을 사용했을 경우  
만약 `BEGIN TRANSACTION;`을 사용한 후 `COMMIT;`을 실행하지 않았다면, **즉시 되돌릴 수 있습니다.**  
```sql
ROLLBACK;
```
위 명령어를 실행하면 변경된 데이터가 복구됩니다.  

---

#### 2️⃣ 트랜잭션을 사용하지 않았을 경우  
만약 트랜잭션 없이 `UPDATE`를 실행했다면, 직접 데이터를 복구해야 합니다.  
이전 데이터를 **백업하지 않았다면** 기존 값으로 되돌리는 것이 어려울 수 있습니다.  

✅ **가능한 복구 방법:**  
1. **백업 테이블에서 복구** (백업이 있을 경우)
   ```sql
   UPDATE tb_his_report AS t
   JOIN tb_his_report_backup AS b ON t.id = b.id
   SET t.category_nm = b.category_nm;
   ```
   → 백업 테이블(`tb_his_report_backup`)이 있다면 그 데이터를 이용해 원래 값으로 복구 가능  

2. **최근 변경된 데이터 찾기**
   ```sql
   SELECT * FROM tb_his_report WHERE category_nm LIKE '%^%';
   ```
   → `%5E`가 `^`로 변경된 데이터를 찾아 수동으로 복구  

3. **수동 복구**
   - `%5E`가 `^`로 변경된 데이터를 다시 원래 값으로 돌리는 SQL 실행  
   ```sql
   UPDATE tb_his_report
   SET category_nm = REPLACE(category_nm, '^', '%5E')
   WHERE category_nm LIKE '%^%';
   ```
