````text
프로그래밍에서 `||`와 `&&`는 논리 연산자로, 조건문에서 주로 사용됩니다. 두 연산자의 차이점은 다음과 같습니다:

### `||` (논리 OR)
`||`는 논리 OR 연산자로, 두 조건 중 하나라도 참이면 전체 조건이 참이 됩니다.
- A || B는 A가 참이거나 B가 참이면 전체 조건이 참이 됩니다.

```c
if (A || B) {
    // A가 참이거나 B가 참이면 이 블록이 실행됩니다.
}
```

### `&&` (논리 AND)
`&&`는 논리 AND 연산자로, 두 조건이 모두 참이어야 전체 조건이 참이 됩니다.
- A && B는 A와 B가 모두 참이어야 전체 조건이 참이 됩니다.

```c
if (A && B) {
    // A와 B가 모두 참이어야 이 블록이 실행됩니다.
}
```

### 예시
```c
int a = 10;
int b = 20;

if (a > 5 || b < 15) {
    // a > 5가 참이므로, 전체 조건이 참이 되어 이 블록이 실행됩니다.
}

if (a > 5 && b < 15) {
    // a > 5는 참이지만, b < 15는 거짓이므로, 전체 조건이 거짓이 되어 이 블록은 실행되지 않습니다.
}
```

이렇게 `||`와 `&&`는 서로 다른 논리적 조건을 결합하여 다양한 조건문을 작성할 수 있도록 해줍니다.
````

````text
예를 들어, 문자열 `"Hello, World!"`에서 `"World"`를 추출한다고 가정해보겠습니다.

### 1. `substring(startIndex, endIndex)`

```javascript
let str = "Hello, World!";
let result = str.substring(7, 12);
console.log(result);  // "World"
```

### 2. `substr(startIndex, length)`

```javascript
let str = "Hello, World!";
let result = str.substr(7, 5);
console.log(result);  // "World"
```

### 3. `slice(startIndex, endIndex)`

```javascript
let str = "Hello, World!";
let result = str.slice(7, 12);
console.log(result);  // "World"
```

각 메서드의 차이점:

- `substring`은 시작 인덱스와 종료 인덱스를 사용하여 문자열의 부분을 추출합니다.
- `substr`은 시작 인덱스와 추출할 길이를 사용합니다. (현재는 사용이 권장되지 않음)
- `slice`는 시작 인덱스와 종료 인덱스를 사용하여 문자열의 부분을 추출합니다. 배열에서도 사용 가능합니다.

세 가지 방법 중 `substring`과 `slice`가 더 많이 사용되며, 상황에 맞게 적절한 메서드를 사용하시면 됩니다.
````
