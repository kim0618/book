## 4. 해결 방법
선택지는 두 가지입니다:

### 방법 A. 서버(DB) 값 수정
- DB에서 `DEPARTURE_HOUR` 값이 `"12"`로 저장된 데이터를 `"11"`로 업데이트하세요.
- 그러면 JSP에서 내려오는 값이 `"11"`이 되어 자동으로 select 박스에서 11시가 선택됩니다.

### 방법 B. 클라이언트 단에서 보정
자바스크립트에서 `"12"`가 들어오면 `"11"`로 치환하도록 수정할 수 있습니다.

```javascript
function Departure_Time_code() {
	var tag = '';
	var OptionValue = ['','06:00','07:00','08:00','09:00','10:00','11:00'];
	var OptionKey   = ['','6','7','8','9','10','11'];

	// JSP 값 가져오기
	var departureHour = "${RMS_INFO[0].DEPARTURE_HOUR}";
	// 12인 경우 11로 강제 변경
	if (departureHour == "12") {
		departureHour = "11";
	}

	for(var i = 0; i < OptionKey.length; i++) {
		if(departureHour == OptionKey[i]) {
			tag += '<option value="' + OptionKey[i] + '" selected>'+ OptionValue[i] +'</option>';
		} else {
			tag += '<option value="' + OptionKey[i] + '">'+ OptionValue[i] +'</option>';
		}
	}
	$('#DEPARTURE_HOUR').append(tag);
}
```
